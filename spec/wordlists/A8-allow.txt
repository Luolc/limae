# A8：「零 + 名词」造词的白名单 (allowlist)。
# 一行一条，`#` 开头是注释，空行忽略。
# 格式与匹配语义的正本是 spec/rules.md「词表」与 A8 条目。
#
# 这张表与 A1 / A3 / A4 / A5 / A7 的词表方向相反：**命中它才不报**。
# 判定按覆盖 (cover) 算 —— 表里某条在行内的某次出现盖住了那个「零」，
# 这一处就不报。所以两侧的固定搭配都用同一张表表达：「零售」盖住
# 「零售价格」里的零，「从零」盖住「从零建一台」里的零。
#
# ## 收词自检 (与 A5 同一条，方向反过来)
#
# 给候选词造一句**无修辞意图的常规中文技术行文**。造得出、读着自然，
# 就该进这张表；造不出的才是 A8 要抓的模型造词 (「零秘密」「零额外
# 请求」「零重复」造不出，所以不收进来)。
#

# ## 左侧固定搭配 (「零」是前一个字的宾语，不是构词的前缀)
#
# 2026-08-31 的 dogfood 上，四份中文语料里「零」左邻的字最多的就是
# 「从」(从零建机、从零一键恢复)，其次是「非」(非零退出)。这些是正
# 当用法，靠覆盖判定豁免。
#
# 「为零」「是零」不收：语料里的「是为零重复」「是零命中」都是
# 「为了 / 就是」加上一个 A8 要抓的造词，收了会把真阳性一起豁免掉。

从零
非零
归零
清零
