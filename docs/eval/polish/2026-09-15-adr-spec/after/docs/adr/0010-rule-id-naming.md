# ADR-0010：规则 id 改名为 `<语言>-<家族>-<序号>`

- 日期：2026-09-01
- 承接：ADR-0007 §一 (规则 id 按家族分前缀) —— 本 ADR 取代该节；ADR-0006 §五 (规则不分语言) 不变，§四 澄清两者的关系；配置层沿用 ADR-0003 (`disable` / `enable` 按规则 id 组织) 与 ADR-0006 §二 (`severity` 同款)

## 背景

规则 id 目前是 `R1`–`R11` (中文排版)、`A1`–`A8` (AI 腔)、`T1`–`T2` (术语选词)。这套命名不是预先设计的，而是逐步积累起来的，现有三个问题：

- **`R` 是历史遗留。** 最早那批规则还没有家族的概念，便叫 R1、R2；「中文排版 (typography)」这个家族名是 ADR-0007 后来加上的，字母与含义对不上 —— `R` 不是 typography 的任何一个音节。
- **单字母前缀不可读。** 从 `A5` 看不出它是英文规则。语言其实是这批规则的固有属性 —— A1–A4、A8 判中文文本，A5–A7 判英文文本，各自有自己的词表 —— 只是没有写进名字，必须翻规范才知道哪条管哪种文本。
- **现在是改名成本最低的时候。** 用户 2026-09-01 核实：三个消费仓 (`machine-setup` / `wealth-management` / `butler`) 都没有配置文件，全部使用默认集，没有任何配置引用规则 id。规则集只会继续增加，消费方也只会继续增多，改得越晚成本越高。

用户 2026-09-01 已裁定改名，格式、映射与取舍均已确定；本 ADR 将这次裁决正式记录下来。**本 ADR 不改任何 id** —— 机械改名由后续任务完成 (见「后果」)。

## 决定

### 一、格式：`<语言>-<家族>-<序号>`

规则 id 统一小写，以连字符分隔，共三段：

- **语言**：规则判定哪种文本 —— `zh` 判中文、`en` 判英文。它是规则自身的属性，不是配置维度，也不改变任何判定行为 (见 §四)。
- **家族**：规则处理哪类问题 —— 当前为 `typography` (字符宽度、空格、标点)、`tell` (AI 腔：套话、句式、黑话、聊天残留、造词)、`word` (该换词或该换说法的地方)。
- **序号**：家族内从 1 开始的十进制整数。**语言 + 家族两段合起来才构成一个序列** —— `zh-tell` 与 `en-tell` 各自编号，不共用序号。

当前的三个前缀因此拆为四个族：`zh-typography`、`zh-tell`、`en-tell`、`zh-word`。

**前缀仍然只是命名，不是新的配置维度** (承接 ADR-0007 §一，与 ADR-0003 §二 一致)：全部规则共用同一个 `disable` / `enable` / `severity` 命名空间，增加一个族不需要新键，也没有「按族开关」或「按语言开关」的写法。**这不是本 ADR 的新决定** —— 这句话原在 ADR-0007 §一 中，本 ADR 取代的正是该节，因此在这里承接：被取代的章节不能再作为源文件，指回去只会把读者带到已作废的内容。

### 二、映射：逐条列全 21 条

| `zh-typography-2` | R2 | 全角括号 |
| `zh-typography-3` | R3 | 半角括号外侧空格 |
| `zh-typography-4` | R4 | CJK 与拉丁字母之间空格 |
| `zh-typography-5` | R5 | CJK 与数字之间空格 |
| `zh-typography-6` | R6 | 数字与 ASCII 单位之间空格 |
| `zh-typography-7` | R7 | 行内代码定界符与 CJK 之间空格 |
| `zh-typography-8` | R8 | 破折号两侧空格 |
| `zh-typography-9` | R9 | 链接与 CJK 之间空格 |
| `zh-typography-10` | R10 | 全角数字 |
| `zh-typography-11` | R11 | 全角标点旁的空格 |

**唯一需要注意的是 `zh-tell-5` = A8**，不是 `zh-tell-8`：中文这一族按 A1、A2、A3、A4、A8 的顺序连续编号，A5–A7 已拆到 `en-tell`，所以 A8 是第 5 条。

每条规则的属性与默认值均逐条不变，源文件仍是 `spec/rules.md` 中的条目 —— 这次只替换 id 字符串。

### 三、密集重排一次，旧 id 不留别名

- **密排**：每个族都从 1 开始独立编号，不为拆走的 A5–A7 在中文族中保留空位。这样每个族各自成序 —— 以后同时给两个族新增规则，也不会争同一个「下一号」。
- **这是唯一一次重排。** 改名后，序号仍然稳定且不复用 (ADR-0007 §一)：删除规则不回收其序号，也不再为填补空位重排。**删除规则留下的空位永久保留，新规则一律使用该族中下一个从未用过的号。**这次可以重排，是因为目前没有消费方在配置中引用规则 id；id 一旦发出，「同一个数字先后指向两条规则」的风险就会出现 —— 因此这次例外仅限这次。
- **旧 id 不留别名**，直接断开：配置中写 `R8` 或 `A5` 后将成为「未知规则 id」，按 ADR-0003 §二 以配置错误退出。这正是需要的失败方式 —— 静默忽略已不存在的 id，会让消费方以为自己关闭了某条规则，实际上它仍在运行。

### 四、id 里带语言不推翻 ADR-0006 §五「规则不分语言」

这一节只澄清一种可能的误读：id 中出现 `zh-` / `en-`，**不**表示规则开始按语言分别开关。

本 ADR 只做一件事 —— 将语言这一规则自身属性写入名称 (§一)。**ADR-0006 §五 确定的行为完全不变，它仍是这件事的源文件**：语言与判定的关系一律以 `docs/adr/0006-rule-grading-fixability-severity-experimental.md` §五 为准，本 ADR 不复述，也不修改。

### 五、家族词的选择与被否掉的候选

- **`typography` 写全词，不缩写**：`typo` 意为「错别字」，歧义过大；`format` 与子命令 `limae format` (ADR-0008 §二) 重名；`punct` 漏掉空格与字符宽度这两类，而它们正是这一族的大多数；`style` 过于宽泛，连 AI 腔那一族也可以包含。
- **`tell` 沿用 ADR-0007 的「AI 腔 (AI tells)」**：这是调研中的原词，指暴露作者身份的破绽，也对应中文所说的「腔调」。
- **`terminology` 改叫 `word`**：其一，`T` 的语义已被 `typography` 占用 (两个族都以 t 开头，缩写会冲突)；其二，T2 原本就不是术语替换，而是判定「秘密」一词的误用，没有唯一替换词 —— `word` 可以涵盖「换词」与「用词不当」两种情况，`terminology` 不可以。

## 后果

- **取代 ADR-0007 §一** 中的前缀表 (`R` / `A` / `T` 三行)。0007 已 accepted，不就地改写；§一以外的各节 (词表放 `spec/wordlists/`、逐行模型、第一批五条与 dogfood 校准数据) 仍全部有效，其中提到的旧 id 是当时的事实记录，保持不变。
- **这是一次 breaking change**，版本按 `0.12.0` 发。旧 id 不保留别名，任何在配置中引用旧 id 的消费方都会收到配置错误，而不是静默降级 —— 作出决定时三个消费仓都没有配置文件，预计实际影响为零。
- **后续的机械改名任务**需要修改以下位置，且只修改 id 字符串：
  - `spec/rules.md` —— 开头的 id 清单、「规则 id 的前缀」一节 (按 §一 与 §二 改写)、21 条规则条目的标题与正文交叉引用、「实验规则清单」、豁免表与修复顺序中的 id、配置示例中的 id (如 `severity` 那个例子)。
  - `spec/fixtures/` —— 50 个 `.findings` 中的 id 列。
  - `spec/wordlists/` —— 8 个文件的文件名 (`A1.txt` → `zh-tell-1.txt`、`A8-allow.txt` → `zh-tell-5-allow.txt`、`T1.toml` → `zh-word-1.toml` 等)，以及 `src/limae/wordlists` 那条目录级软链所指。
  - `src/` 与 `tests/` —— id 常量、以 id 命名的函数与测试名。
  - `docs/` —— 仍描述当前状态的正文 (如 `docs/tracker.md`)。**ADR 正文中的历史叙述不改**：那是当时的事实记录，修改会变成篡改。
  - `pyproject.toml` 的版本与 `README.md` 中的示例。
- **改名不得改变任何判定行为**：黄金集的命中行号与命中条数必须与改名前逐条一致，只有 id 字符串变化。验收方式是改名前后各跑一次全量，比对除 id 列外的全部输出。
- 本 ADR 不改任何 id、不动 `spec/`、不动代码、不动 `pyproject.toml`。

## 状态

accepted (2026-09-01)。
