# lo-md-lint 规则规范

本文件是规则的正本 (normative)，语言无关：任何实现 (implementation) 都按这里的判定与修复行为工作，并以 `spec/fixtures/` 的黄金集 (golden fixtures) 验收。规范是上游——实现与规范不一致时先改规范、再改实现 (ADR-0001)。

规则 id 稳定且不复用，当前是 R1 / R2 / R3；实现报告违规时用的 id 必须与这里一致。fixture 格式与 runner 的判定见 `spec/README.md`。

## 通用模型

### 处理单位

- **逐行判定**：一个违规永远落在一行之内，报告的位置就是「行号 + 规则 id」。
- **逐行修复**：`--fix` 只在行内改写，不增删行、不改变行数，因此输入与期望输出逐行对齐。
- **一行内的修复顺序是 R2 → R1 → R3**：先把全角括号换成半角，再转 CJK 旁的标点，最后补括号外侧的空格。所以 `术语（covered call）策略` 报的是两处 R2，修完却是 `术语 (covered call) 策略`——R2 的产物立刻落进 R3 的判定范围。
- **检查只看原文**：`check` 报告的是修复前文本上的违规，不预测修复后会不会产生新的违规。

### CJK 与 word 字符

- **CJK 字符**指 U+4E00–U+9FFF (中日韩统一表意文字基本区)。
- **word 字符**指 `A-Za-z0-9` 与 CJK 字符。

### 全局豁免

下面两类内容对所有规则豁免：既不报违规，`--fix` 也原样输出。

1. **围栏代码块 (fenced code block)**：去掉行首空白后以 ` ``` ` 或 `~~~` 开头的行是围栏行；围栏行本身与两条围栏之间的全部内容都豁免。
2. **行内代码 (inline code span)**：按 CommonMark 的反引号串规则——一段连续反引号开启一个 span，由下一段**等长**的反引号串闭合；找不到等长闭合串的反引号串是普通文本。豁免的是两条定界串**之间**的内容；定界反引号本身算正文，所以 `` `code`(x) `` 仍然报 R3。
   - 一个 span 可以跨行，但不跨块 (block)：空行截断，下列块起始也截断——ATX 标题 `#`、表格行 `|`、主题分隔线、无序列表项 `-` / `*` / `+`、有序列表项 `1.` / `1)`、引用块 `>`；例外是连续的 `>` 行属于同一个引用块段落，彼此不截断。

## 配置

规则**默认全部启用**，配置只能关掉规则：关掉的规则既不报违规，`--fix` 也原样输出。所以「没有任何配置」永远等价于「全开」，各实现的默认行为一致，消费方不加配置就不会有行为变化。

### 键

只有一个键 `disable`——要关掉的规则 id 列表，元素是本文件里的稳定 id：

```toml
disable = ["R3"]
```

- `disable = []` 与不写这个键等价，都是全开。
- 未知 id (不在本规范里的字符串) 是配置错误，实现必须报错退出而不是静默忽略；id 拼错或规则改名会立刻暴露。
- 键按规则 id 组织，与规则集无关：将来加英文规则，它们的 id 直接写进同一个 `disable`，不需要新键，也不需要「中文 / 英文」这类分组。

### 来源与优先级

两类来源，**CLI flag 优先于配置文件**；一次运行只有一个来源生效，不做逐键合并。

1. **CLI flag `--disable`**：接规则 id，可重复给也可逗号分隔——`--disable R3`、`--disable R1,R3`、`--disable R1 --disable R3` 等价于关掉列出的规则。命令行上只要出现了 `--disable`，配置文件整体不生效。
2. **配置文件**：两种同构 (isomorphic) 载体，见下。

`--fix` 与 `--all` 的语义不受配置影响。

### 配置文件的两种载体

两者键结构完全一致，只是外层位置不同：

- **独立文件 `lo-md-lint.toml`**：键写在顶层。

  ```toml
  disable = ["R3"]
  ```

- **`pyproject.toml` 的 `[tool.lo-md-lint]` 表**：同样的键写在这张表里。

  ```toml
  [tool.lo-md-lint]
  disable = ["R3"]
  ```

### 发现顺序

从**当前工作目录 (cwd)** 开始逐级向上找，最近的一层生效，找到就停：

1. 该层有 `lo-md-lint.toml` → 用它。
2. 否则该层的 `pyproject.toml` 有 `[tool.lo-md-lint]` 表 → 用它。同一层两者都在时 `lo-md-lint.toml` 赢。
3. 都没有 → 上一级重复。含 `.git` 的目录 (仓库根) 是最后一层，其上不再找；不在仓库里时找到文件系统根为止。一层都没找到就是默认全开。

没有 `[tool.lo-md-lint]` 表的 `pyproject.toml` 不是配置来源，遇到了继续向上找。**发现只看 cwd，不看被检文件的路径**：一次运行一套配置，被检文件在哪个目录都用同一套规则。

## R1：CJK 旁的半角标点

- **判定**：`,` `;` `:` `?` `!` 五个半角标点之一，紧邻的前一个或后一个字符是 CJK 字符。等价于正则 `[CJK][,;:?!]|[,;:?!][CJK]` 的非重叠匹配，所以 `你好,世界` 只报一处。
- **修复**：换成全角对应字符——`,` → `，`、`;` → `；`、`:` → `：`、`?` → `？`、`!` → `！`。
- **不触发**：两侧都不是 CJK 的半角标点原样保留。

```text
你好,世界        → 你好，世界        (R1)
ACME,主动层      → ACME，主动层      (R1，后一个字符是 CJK)
a, b: c; d? e!   → 不变
$1,000           → 不变
https://example.com:8080 → 不变
```

## R2：全角括号

- **判定**：出现 `（` 或 `）`。**每个字符各报一处**，所以 `（测试）` 报两处 R2。
- **修复**：分别换成 `(` 与 `)`；换完之后 R3 在同一次修复里继续处理外侧空格。

```text
（测试）                  → (测试)                    (R2 ×2)
术语（covered call）策略   → 术语 (covered call) 策略   (R2 ×2)
[链接](url)（注）         → [链接](url) (注)          (R2 ×2；换成半角后由 R3 补空格)
```

## R3：半角括号外侧空格

半角括号的外侧与相邻文字之间要留一个空格，内侧不留。两个方向共用 id `R3`，各自独立报告；检测与修复对称——凡报的每一处 `--fix` 都补空格。

- **判定 (左)**：`(` 的前一个字符是 word 字符或 `)`，或 `(` 前面紧跟 `**`，或紧跟一个反引号 `` ` ``。`)(` 之间要空格，是因为前一个括号组是文字而不是语法。
- **判定 (右)**：`)` 的后一个字符是 word 字符或一个反引号 `` ` ``，或 `)` 后面紧跟 `**` 再跟一个 word 字符。`**` 后面不跟 word 字符时不报：那是粗体的收尾标记 (`**加粗 (x)**`)，插空格会破坏它；反过来 `)**` 后跟 word 字符的 `**` 按 CommonMark 的 flanking 规则不可能收尾，只能是起始标记。
- **修复**：在 `(` 前、`)` 后补一个空格。
- **豁免 (只对左方向)**：
  - **英文 token 内的括号**：`(` 的前一个与后一个字符都是 ASCII 字母或数字，如 `credential(s)`、`word(s)`、`401(k)`、`f(x)`——括号是这个英文 token 的一部分，不是行文标点 (语言规范：纯英文内容保留半角标点)。右方向不豁免，所以 `401(k)计划` 仍要求 `)` 后有空格。
  - **Markdown 链接**：`]` 不算相邻文字，`](` 是链接语法而不是行文，所以 `[链接](url)` 不报。

```text
期权(covered call)策略  → 期权 (covered call) 策略   (R3 ×2)
Foo(核心)               → Foo (核心)                (R3)
**粗体**(x)             → **粗体** (x)              (R3)
(x)**粗体**             → (x) **粗体**              (R3)
`code`(x)               → `code` (x)                (R3)
(x)`code`               → (x) `code`                (R3)
查 401(k)计划            → 查 401(k) 计划            (R3，只报右方向)
选 option(s)后接中文     → 选 option(s) 后接中文      (R3，只报右方向)
逐字引用 credential(s) 的文案 → 不变
[链接](url)(注)          → [链接](url) (注)          (R3，`)(` 之间)
[链接](https://example.com) 后文 → 不变
```
