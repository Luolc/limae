# ADR-0011：A/B 回注只带编号，不带型号名

- 日期：2026-09-01
- 取代：ADR-0009 §五 关于「回注内容」的部分 (回注机制本身、只在命中 A/B 的那一轮回注、台账落会话态，均不变)

## 背景

ADR-0009 §五 决定「把编号与 A、B 各自用的型号名，通过 `Stop` hook 的 `additionalContext` 注回会话」。它的依据写得很清楚，是本机二进制里的一句 schema 描述：

> Hook-specific output for the Stop event. additionalContext is non-error feedback delivered to the model; the conversation continues so the model can act on it.

ADR-0009 从这句读出一个对照：`MessageDisplay` 的输出「模型看不到」，`Stop` 的 `additionalContext`「delivered to the model」，于是把它当成一条**只通向模型**的通道 —— §五 整条决定「正是靠这个对照成立的」。

**这个推论是错的，2026-09-01 实测推翻。** 宿主 Claude Code `2.1.258`：`Stop` hook 的 `additionalContext` 被包进一条 `stop_hook_summary` 系统消息 (字段 `hookAdditionalContext`)，在屏幕上渲染成 `Stop hook feedback: …`，与 hook 的错误同列。渲染逻辑两处一致 —— **错误数为 0、`additionalContext` 为空、且没有阻断续跑时，这条摘要返回 `hidden`**。也就是说：**提供 `additionalContext` 这个动作本身，正是让它从隐藏变为显示的原因。**

那句 schema 说的是它**进不进模型上下文**，不是它**对用户可不可见**。两者不互斥，而 ADR-0009 把前者读成了后者。

后果是直接的：屏幕上原文之后是 A、B 两栏 (故意不写型号)，再往下就是我们自己注回的那句，写着「A = 某型号，B = 某型号」。**答案印在了盲评题的旁边。** 用户 2026-09-01 用截图指出这一点。

## 决定

**回注只写编号，不写型号名。** 屏幕上的两栏与回注这一句都不再包含任何型号信息；编号到型号的对应关系只留在会话态台账里，回注里给出台账路径，需要时由 agent 自己去读。

回注文本同时**写短**：它必然上屏，而宿主对这条摘要有截断。

**回注的措辞不再声称「上一条回复」。** `Stop` 每轮只触发一次、在轮末；而一轮里可以有很多条助手消息，A/B 只发生在其中一条上。实测到过 47 分钟、数十条消息之后才被 `Stop` 宣布的情形，「上一条回复」在那时是假的。改为「本轮有一次 A/B 对照」。

**回注仍然一轮只发一次** (靠消费 pending 文件实现)，这一条不是风格而是硬约束：`additionalContext` 是让对话继续的非错误反馈，一个总是返回内容的 `Stop` hook 会把自己反复触发 —— 同日实测，一个恒定返回字符串的 hook 把「Say only: hello」变成了五轮以上还在继续。

## 后果

- **已经采到的偏好判据要降级。** 在本 ADR 之前，用户按编号给出的两轮判词 (`罗盘`、`屋檐`) 是在屏幕上能看到型号名的情况下给的，**严格说不是盲评结果**。它们仍是「哪段文字更好」的有效读后感，但**不能当作型号的证据**用于 ADR-0008 §五 的默认型号决定。将来做统计的人必须把这两轮排除，或至少标注。
- **ADR-0009 §一 的「支点」推论只在 `MessageDisplay` 这一侧仍然成立**：被润色的文本不写回 transcript、不进模型上下文，这一条有二进制里两句独立的描述串支撑，本 ADR 不触碰。被推翻的只是「`Stop` 这条通道只通向模型」这一句 —— 它是 ADR-0009 自己从对照里推出来的，没有实测支撑。
- **模型仍然接得上话**：它从回注知道「本轮有一次 A/B、编号是某某」，需要对应关系时读台账。少一次便利，换回盲评的有效性。
- **A/B 目前是关闭的** (`LIMAE_HOOK_AB_RATE=0`，由用户关闭)。本 ADR 落地是重新打开它的前提之一 —— 盲评坏着的时候，采回来的判据是废的。**重新打开由用户决定，不由实现方决定。**
- 候选池构成、hook 挂载的事件、回注机制本身都不变，因此不需要再动 ADR-0008 §五 与 ADR-0009 的其余各条。

## 状态

accepted (2026-09-01)。
