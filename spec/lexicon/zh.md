# AI 中文词典

一部给机器写的中文里的怪词典。收的不是错字，是**读得懂却没人这么说**的词 —— 从英文逐字译来的、把两个熟词硬凑的、为了显得干脆而压掉成分的。

它们难被发现，正因为读得懂：读者能从「探针」反推回 probe、从「正本」反推回 canonical，于是确实读懂了，读懂了就不会报错，于是它以「读起来怪，但能懂，算了」的形式一路通过。看不懂的词活不过一天，读得懂的怪词能在一个仓库里铺开几十处。

每个词条给三样：它实际想说什么、中文里怎么说、几个带上下文的例子。用法有二：喂给润色模型当判据，或者转成词表交给 linter 直接报。

判据只有一条：**一个母语者会不会这样说**，不是「读者能不能看懂」。后者对这一整类退化全盲。

---

## 正本

意思是「以哪一份为准」。「正本」与「副本」相对，指有法律效力的原件，用来说「同一个事实唯一权威的那份」是把法律文书的词借到了工程里。

- 规则语义的**正本**在 `spec/rules.md`，这里只记还没做的事。
  → 规则语义**以 `spec/rules.md` 为准**，这里只记还没做的事。
- backlog 的**正本**，由 orchestra 在合入后记账。
  → backlog **写在这里**，别处不重复，由 orchestra 在合入后记账。
- 形制的**正本**是 ADR-0008 第 9 节。
  → 形制**由 ADR-0008 第 9 节定**。
- 项目级 skill **正本**在 `.agents/skills/`，不装到用户级目录。
  → 项目级 skill **只放在** `.agents/skills/`，不装到用户级目录。

## 测量装置

意思是「记录」或「台账」。从 apparatus 一类的词译来；中文里「装置」指实物设备，不用来说一份数据记录。

- 今天到此为止，六个 PR 全部合入，两份新决定，**测量装置在跑**而且样本是干净的。
  → 今天到此为止，六个 PR 全部合入，两份新决定，**记录在跑**，样本也干净。
- PR 已合入，从现在起每一次润色都会留下三份文本。**测量装置装好了。**
  → PR 已合入，从现在起每一次润色都会留下三份文本。**现在能记录了。**
- ⑦ 是**测量装置**，⑧⑨ 的验收都要靠它。
  → ⑦ 是**用来观察的那一层**，⑧⑨ 的验收都要靠它。

## 按住不动

意思是「先不动手」。「按住」在中文里是用手压住某物不放，用它说「暂缓推进」没有这个引申义。

- **接下来我按住不动**，等真实的单路记录攒够。
  → **接下来我先停一下**，等真实的单路记录攒够。
- 这条先**按住不动**，等额度恢复再说。
  → 这条**先放着**，等额度恢复再说。

## 扶正

意思是「按你说的改」。「扶正」是把歪的东西扶直，或旧时把偏房立为正室，都与「采纳一个说法」无关。

- 你补的那句旁证比你自己以为的更重要，**我要把它扶正**。
  → 你补的那句旁证比你自己以为的更重要，**这话说得比我准，按你的来**。
- 这个判断我**扶正**一下：不是模型违规，是规则不存在。
  → 这个判断我**改一下**：不是模型违规，是规则不存在。

## 长出来的

意思是「新发现的」。事情不会自己长出来，这是把 emerge 直译过来又当成了动词短语。

- 去掉一条已完成的，补四条今天**长出来的**。
  → 去掉一条已完成的，补四条**今天新发现的**。
- 这几条是做的过程中**长出来的**待办。
  → 这几条是**做的过程中冒出来的**待办。

## 收下

意思是「记住了」或「接受」。「收下」的宾语是实物 (收下礼物)，用来接收一条意见或一项规矩不是中文的说法。

- 这条规矩**收下**，以后引规范先贴原文。
  → 这条规矩**记住了**，以后引规范先贴原文。
- 你的更正我**收下**。
  → 你的更正我**接受**。

## 兜住

意思是「挡住」或「拦下」。「兜住」是用衣兜、网兜把落下的东西接住，作为「兜底」的口语缩略进技术文档嫌松散，且常与「兜底」混用。

- 这条断言**兜住**了那个退化实现。
  → 这条断言**拦住**了那个退化实现。
- CI 那一步**兜住**漏装钩子的分支。
  → CI 那一步**挡住**漏装钩子的分支。

## 探针预注册

意思是「开跑前把摸底试跑的判读标准定死」。probe 与 preregistration 逐字译来；中文里「探针」是物理的针或性能剖析插的探针，没有「小规模试跑」这个义项，而这个意思中文本来就有词。

- `#368` (**探针预注册**) 我让它从 2×1 改成 2×2。
  → `#368` (**摸底试跑的判读标准**) 我让它从 2×1 改成 2×2。
- **探针**只是**预注册**，实验还没跑。
  → **摸底试跑的标准只是先冻结下来**，实验还没跑。

## 电报体

不是一个词，是一种句式：为了显得干脆而省掉主语、连接词或动词，把话压成判断句。省略之后意思仍然唯一，所以读得懂；但读者要自己把成分补回去。

- **规则就在那儿，模型没执行。**
  → **模型没有执行这个规则。**
- **关着的路排在活着的路后面。**
  → **没人用的先放着，正在用的先修。**
- **检查跑了，但被检查的量不是你以为的那个量。**
  → **检查确实跑了，但它检查的东西不是你以为的那个。**

陈述状态、列条目、表格单元格里的短句本来就不带主语，那不是电报体，不要为了「完整」把它们撑长。

## 格言式收尾

也不是一个词，是一种习惯：段落结尾拔高成一句可以印在墙上的话。它读起来像结论，实际往往只是把上一句换个说法再说一遍。

- 一个属性如果靠「没人去用那条路径」成立，**它就不是属性，是约定**。
  → 这条路径没人用，不等于它不能被用；要么删掉它，要么它就是个缺口。
- 换措辞不等于修好。**软化只是让它更难被发现。**
  → 一个声称撑不住是因为缺证据，把词换软不会补上证据。

要去掉的是拔高的措辞，不是结论本身 —— 那句话往往同时是本段唯一的论断，整句删掉就丢了一个意思。
