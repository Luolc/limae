# ADR-0010：规则 id 改名为 `<语言>-<家族>-<序号>`

- 日期：2026-09-01
- 承接：ADR-0007 §一 (规则 id 按家族分前缀) —— 本 ADR 取代它；ADR-0006 §五 (规则不分语言) 不变，§四 澄清两者的关系；配置层沿用 ADR-0003 (`disable` / `enable` 按规则 id 组织) 与 ADR-0006 §二 (`severity` 同款)

## 背景

规则 id 现在是 `R1`–`R11` (中文排版)、`A1`–`A8` (AI 腔)、`T1`–`T2` (术语选词)。这套命名是一步步长出来的，不是设计出来的，今天有三个问题：

- **`R` 是历史遗留。** 最早那批规则没有家族的概念，就叫 R1、R2；「中文排版 (typography)」这个家族名是 ADR-0007 事后安上去的，字母与含义对不上 —— `R` 不是 typography 任何一个音节。
- **单字母前缀不可读。** `A5` 看不出是英文规则。语言其实是这批规则的真实属性 —— A1–A4、A8 判的是中文文本，A5–A7 判的是英文文本，各自有各自的词表 —— 只是没写进名字，得翻规范才知道哪条管哪种文本。
- **现在是改名最便宜的时刻。** 用户 2026-09-01 核实：三个消费仓 (`machine-setup` / `wealth-management` / `butler`) 都没有配置文件，全跑默认集，没有任何一处在配置里引用规则 id。规则集只会继续长大，消费方只会继续增多，晚改一天就贵一天。

用户 2026-09-01 裁定改名，格式、映射与取舍都已拍板；本 ADR 是这次裁决的正式落库。**本 ADR 不改任何 id** —— 机械改名是后续任务 (见「后果」)。

## 决定

### 一、格式：`<语言>-<家族>-<序号>`

规则 id 一律小写、连字符分隔，三段：

- **语言**：这条规则判的是哪种文本 —— `zh` 判中文、`en` 判英文。它是规则自身的性质，不是配置维度，也不改变任何判定行为 (见 §四)。
- **家族**：这条规则管哪一类问题 —— 当前是 `typography` (字符宽度、空格、标点)、`tell` (AI 腔：套话、句式、黑话、聊天残留、造词)、`word` (该换词或该换说法的地方)。
- **序号**：家族内从 1 开始的十进制整数。**语言 + 家族两段合起来才是一个序列** —— `zh-tell` 与 `en-tell` 各排各的，不共用序号。

当前的三个前缀因此变成四个族：`zh-typography`、`zh-tell`、`en-tell`、`zh-word`。

**前缀仍然只是命名，不是新的配置维度** —— 这一点与 ADR-0007 §一完全一致：全部规则共用同一个 `disable` / `enable` / `severity` 命名空间，加一个族不需要新键，也没有「按族开关」或「按语言开关」的写法。

### 二、映射：逐条列全 21 条

| 新 id | 旧 id | 规则名 |
| --- | --- | --- |
| `zh-typography-1` | R1 | CJK 旁的半角标点 |
| `zh-typography-2` | R2 | 全角括号 |
| `zh-typography-3` | R3 | 半角括号外侧空格 |
| `zh-typography-4` | R4 | CJK 与拉丁字母之间空格 |
| `zh-typography-5` | R5 | CJK 与数字之间空格 |
| `zh-typography-6` | R6 | 数字与 ASCII 单位之间空格 |
| `zh-typography-7` | R7 | 行内代码定界符与 CJK 之间空格 |
| `zh-typography-8` | R8 | 破折号两侧空格 |
| `zh-typography-9` | R9 | 链接与 CJK 之间空格 (默认关闭) |
| `zh-typography-10` | R10 | 全角数字 |
| `zh-typography-11` | R11 | 全角标点旁的空格 |
| `zh-tell-1` | A1 | 中文套话 |
| `zh-tell-2` | A2 | 否定平行 |
| `zh-tell-3` | A3 | 互联网黑话 |
| `zh-tell-4` | A4 | 聊天残留 |
| `zh-tell-5` | **A8** | 「零 + 名词」造词 |
| `en-tell-1` | A5 | 英文 AI 词汇 |
| `en-tell-2` | A6 | 英文否定平行 |

| `zh-word-1` | T1 | 术语选词 |
| `zh-word-2` | T2 | 「秘密」误用 |

**唯一需要当心的一行是 `zh-tell-5` = A8**，不是 `zh-tell-8`：中文那一族按 A1、A2、A3、A4、A8 的顺序密排，A5–A7 被拆去了 `en-tell`，所以 A8 落在第 5 位。

三轴属性 (可修复性 / 严重度 / 成熟度) 逐条不变，R9 的「默认关闭」也不变 —— 这次只换 id 字符串。

### 三、密集重排一次，旧 id 不留别名

- **密排**：每个族从 1 开始独立编号，不给拆走的 A5–A7 在中文族里留空位。理由是让每个族各自成序 —— 以后同时给两个族加规则，不会争同一个「下一号」。
- **这是一次性的重排。** 改完之后，序号照旧稳定且不复用 (ADR-0007 §一)：删掉一条规则不回收它的号，也不再为了填洞重排一次。
- **旧 id 不留别名**，干净断裂：配置里写 `R8` 或 `A5` 从此是「未知规则 id」，按 ADR-0003 §二 报配置错误退出。这正是想要的失败方式 —— 静默忽略一个已经不存在的 id，会让消费方以为自己关掉了某条规则，其实它一直在跑。

### 四、id 里带语言不推翻 ADR-0006 §五「规则不分语言」

这一条必须写明，否则以后会有人读到 `zh-` / `en-` 前缀，以为我们反悔了。

**ADR-0006 §五 讲的是行为**：不做语言探测、不按文件或目录指定语言、不给规则加一个「语言」的配置维度，规则对文本本身生效 —— 英文 tell 出现在中文文档里照样报，中文排版规则不因为一份文档「是英文的」就整体关掉。这一条**继续有效，一字不改**。

**本 ADR 讲的是名字**：`en-tell-1` 里的 `en` 说明这条规则判的是英文文本 (它的词表全是英文词，只可能命中英文串)，与「这份文档是什么语言」无关，也不引入任何按语言开关的入口。改名不改变任何一条规则的判定、启用集、默认严重度或报告位置 —— 黄金集除 id 字符串外逐字不变，命中的行号与条数逐条一致。

一句话：**语言在这里是规则的属性，从来不是文档的属性。** 名字把这个早就存在的属性写了出来，仅此而已。

### 五、家族词的选择与被否掉的候选

- **`typography` 写全词，不缩写**：`typo` 是「错别字」的意思，歧义太大；`format` 与子命令 `limae format` (ADR-0008 §二) 撞名；`punct` 漏掉了空格与字符宽度这两类，而它们正是这一族的多数；`style` 太泛，泛到可以装下 AI 腔那一族。
- **`tell` 沿用 ADR-0007 的「AI 腔 (AI tells)」**：调研里的原词，指暴露作者身份的破绽，与「腔调」这个中文说法对得上。
- **`terminology` 改叫 `word`**：一来 `T` 已经被 `typography` 的语义占走 (两个族都以 t 开头，缩写会撞)；二来 T2 本来就不是术语替换，它判的是「秘密」这个词的误用，没有唯一替换 —— `word` 装得下「换词」与「用词不当」两种，`terminology` 装不下。

## 后果

- **取代 ADR-0007 §一** 那张前缀表 (`R` / `A` / `T` 三行)。0007 是 accepted，不就地改写；§一之外的各节 (词表放 `spec/wordlists/`、逐行模型、第一批五条与 dogfood 校准数据) 全部仍然有效，其中提到的旧 id 是当时的事实记录，照旧不改。
- **这是一次 breaking change**，版本按 `0.12.0` 发。旧 id 不留别名，任何在配置里引用旧 id 的消费方会拿到配置错误而不是静默降级 —— 决定作出时三个消费仓都没有配置文件，预期实际影响为零。
- **后续的机械改名任务**要动这些地方，且只动 id 字符串：
  - `spec/rules.md` —— 开头的 id 清单、「规则 id 的前缀」一节 (按 §一 与 §二 改写)、21 条规则条目的标题与正文交叉引用、「实验规则清单」、豁免表与修复顺序里的 id、配置示例里的 id (如 `severity` 那个例子)。
  - `spec/fixtures/` —— 50 个 `.findings` 里的 id 列。
  - `spec/wordlists/` —— 8 个文件的文件名 (`A1.txt` → `zh-tell-1.txt`、`A8-allow.txt` → `zh-tell-5-allow.txt`、`T1.toml` → `zh-word-1.toml` 等)，以及 `src/limae/wordlists` 那条目录级软链所指。
  - `src/` 与 `tests/` —— id 常量、以 id 命名的函数与测试名。
  - `docs/` —— 仍在描述当前状态的正文 (如 `docs/tracker.md`)。**ADR 正文里的历史叙述不改**：那是当时的事实记录，改了就成了篡改。
  - `pyproject.toml` 的版本与 `README.md` 里的示例。
- **改名不得改变任何判定行为**：黄金集的命中行号与命中条数必须与改名前逐条一致，只有 id 字符串变。验收方式是改名前后各跑一次全量、比对除 id 列外的全部输出。
- 本 ADR 不改任何 id、不动 `spec/`、不动代码、不动 `pyproject.toml`。

## 状态

accepted (2026-09-01)。
