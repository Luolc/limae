## Where the text comes from

The text to rewrite is the file `{path}` of a repository. You are started
in a directory that holds a copy of that repository's tracked files. You
may read other files there to keep terminology, names and cross-references
consistent with the rest of the repository. Rewrite nothing you find there,
and change nothing on disk: the rewrite is returned, not written. The text
still arrives as the material to rewrite; return only its rewrite.
