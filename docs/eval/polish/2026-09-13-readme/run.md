## 合入前的手工修正

`after.md` 是**模型的纯产物**，不含下面这两处 —— 样本要记模型实际写出来的东西，不是我改过之后的。进仓的 `README.md` 在它之上多了这两处：

| 模型写的 | 改成 |
| --- | --- |
| 两者的语义都**在** `spec/rules.md`「行内指令」「忽略文件」。 | 两者的语义都**以** ……**为准**。 |
| 全部键、发现顺序和配置错误的判定，**见** `spec/rules.md`「配置」。 | ……都**以** ……**为准**。 |

两处是同一个形状：原文四处「正本」里，模型有两处换成了「以……为准」(对)，另两处换成了「见」「都在」—— **丢掉了「以它为准」这个断言**。这是语义改动，不是语域改动，所以补回。同一份文件里同一个词被换成两种不同的东西，这件事本身也值得作为一条读数留着。
