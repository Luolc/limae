# ADR-0011：A/B 回注只带编号，不带型号名

- 日期：2026-09-01
- 取代：ADR-0009 §五 关于「回注内容」的部分 (回注机制本身、只在命中 A/B 的那一轮回注、台账落会话态，均不变)

## 背景

ADR-0009 §五 决定「把编号与 A、B 各自用的型号名，通过 `Stop` hook 的 `additionalContext` 注回会话」。依据是本机二进制里的一句 schema 描述：

> Hook-specific output for the Stop event. additionalContext is non-error feedback delivered to the model; the conversation continues so the model can act on it.

ADR-0009 从这句得出一个对照：`MessageDisplay` 的输出「模型看不到」，`Stop` 的 `additionalContext`「delivered to the model」，于是把它当成一条**只通向模型**的通道 —— §五 整条决定「正是靠这个对照成立的」。

**这个推论是错的，2026-09-01 的实测已推翻它。** 宿主 Claude Code `2.1.258` 会把 `Stop` hook 的 `additionalContext` 包进一条 `stop_hook_summary` 系统消息 (字段 `hookAdditionalContext`)，并在屏幕上渲染为 `Stop hook feedback: …`，与 hook 错误并列。两处渲染逻辑一致 —— **错误数为 0、`additionalContext` 为空、且没有阻断续跑时，这条摘要返回 `hidden`**。也就是说：**正是提供了 `additionalContext`，才让它从隐藏变成显示。**

那句 schema 说明的是它**是否进入模型上下文**，不是它**是否对用户可见**。两者并不互斥，但 ADR-0009 把前者当成了后者。

后果很直接：屏幕上先是原文，然后是 A、B 两栏 (故意不写型号)，下面紧接着我们自己注回的一句「A = 某型号，B = 某型号」。**答案就印在盲评题旁边。** 用户 2026-09-01 用截图指出了这一点。

## 决定

**回注只写编号，不写型号名。** 屏幕上的两栏和回注都不再包含任何型号信息；编号与型号的对应关系只保留在会话态台账中，回注提供台账路径，需要时由 agent 自己读取。

回注文本同时**缩短**：它必然显示在屏幕上，而宿主会截断这条摘要。

**回注不再说「上一条回复」。** `Stop` 每轮只触发一次，且在轮末；一轮中可以有很多条助手消息，A/B 只发生在其中一条。实测中，`Stop` 曾在 47 分钟、数十条消息后才触发，「上一条回复」在这种情况下并不成立。改为「本轮有一次 A/B 对照」。

**回注仍然一轮只发一次** (靠消费 pending 文件实现)。这不是风格问题，而是硬约束：`additionalContext` 是让对话继续的非错误反馈，持续返回内容的 `Stop` hook 会反复触发自己 —— 同日实测，一个恒定返回字符串的 hook 让「Say only: hello」在五轮以上仍未停止。

## 后果

- **已经采到的偏好判据要降级。** 本 ADR 之前，用户按编号给出的两轮判词 (`罗盘`、`屋檐`) 都是在屏幕上可见型号名的情况下给出的，**严格说不是盲评结果**。它们仍是「哪段文字更好」的有效读后感，但**不能作为型号证据**用于 ADR-0008 §五 的默认型号决定。将来做统计时，必须排除这两轮，或至少作出标注。
- **ADR-0009 §一 的「支点」推论只在 `MessageDisplay` 一侧仍然成立**：被润色的文本不会写回 transcript，也不进入模型上下文。这一点有二进制中两句独立的描述串支持，本 ADR 不涉及。被推翻的只有「`Stop` 这条通道只通向模型」这句话 —— 它是 ADR-0009 自己从对照中推出来的，没有实测支持。
- **模型仍然能接着处理**：它会从回注得知「本轮有一次 A/B、编号是某某」，需要对应关系时再读取台账。少了一次便利，换回盲评的有效性。
- **A/B 目前是关闭的** (`LIMAE_HOOK_AB_RATE=0`，由用户关闭)。本 ADR 落地是重新打开它的前提之一 —— 盲评失效时，采回来的判据也无效。**是否重新打开由用户决定，不由实现方决定。**
- 候选池构成、hook 挂载的事件、回注机制本身都不变，因此不需要再修改 ADR-0008 §五 与 ADR-0009 的其余内容。

## 状态

accepted (2026-09-01)。
