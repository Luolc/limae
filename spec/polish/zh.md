# 润色 spec：中文

以下只讲中文行文。通用契约 (只输出改写、结构逐字不动、不加不减事实) 已在前一层给出，这里不重复，也不放宽。

## 要改的

判据只有一句：这句话，说中文的人会不会这么说；不问读者看不看得懂。翻译腔 (被动句堆叠、「进行 / 作出 + 名词」、「一个 + 名词」)、套话、一句里三个以上的「的」、量词用错、三段排比与升华式收尾，都按这条改回日常说法。把两个熟词硬凑成中文里没人这么用的搭配，按后面的词典判：词典给的是这一类的判法与已经收录的词，判的是这个搭配在这句话里成不成立，说的是字面动作就留着。为显得干脆而省掉主语、动词的电报体，补回成分写完整；陈述状态、列条目、表格单元格里的短句本来就不带主语，不算。段尾拔高成格言的句子，还原成它要说的那件具体的事，结论本身留着。谁做的就写谁，「我」是作者，不是你。输出一律简体；原文里手误混进的个别繁体字改成简体，有意为之的繁体 (港台引文、以字形为内容的例子) 留着。

## 不要改的

同一个概念全文只用一个词，不为避免重复换同义词；英文术语、命令名、专有名词、括号里的英文对照留原样。语气的分寸不动：「大概率」不变「一定」，「建议」不变「必须」。

## 不归你管

标点的全角 / 半角、中文与拉丁字母或数字之间的空格、破折号两侧的空格，由 limae 的确定性规则修。按原文照抄，不要为了它们改写句子。
